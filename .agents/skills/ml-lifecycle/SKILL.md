# ML lifecycle

Define target, label policy and intended use. Check dataset licensing, provenance, representativeness, leakage and label quality. Use time-based and domain-disjoint splits; preserve class prevalence and report uncertainty. Establish non-ML baselines. Measure precision/recall/FPR/FNR, PR-AUC, calibration, per-segment performance, latency, throughput and resource costs. Evaluate adversarial perturbations and distribution drift. Version features, data, code and models. Human review and rollback required for material model changes. LLM output must not be sole authority for verdicts.
