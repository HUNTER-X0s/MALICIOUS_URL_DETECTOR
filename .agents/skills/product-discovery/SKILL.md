# Product discovery

Define users, jobs-to-be-done, pain points, existing alternatives, misuse cases and value proposition. Convert findings into user stories with acceptance criteria, priority, evidence, dependencies, analytics and privacy implications. Distinguish MVP requirements from future options. Do not add features without user value, validation, ownership and measurable outcomes. Save PRDs and roadmap updates in `records/product/`.
