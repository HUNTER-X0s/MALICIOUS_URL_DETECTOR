# Incident response

Define severity, on-call ownership, detection, triage, containment, eradication, recovery, communication and postmortem. Cover service compromise, scanner escape, signing key compromise, feed poisoning, extension supply-chain incident, customer data exposure, false-positive/negative waves and provider outage. Define kill switches, revocation, key rotation, feed disablement, scanner isolation, tenant notification and evidence preservation. Run tabletop and recovery exercises; never claim 24/7 response until staffed and tested.
