# DevSecOps and release

Design reproducible builds, protected branches, code review, secret scanning, SAST, dependency/SCA, license checks, container/IaC scanning, SBOM, artifact signing/provenance where appropriate, test gates and environment promotion. Use least-privilege short-lived credentials. Separate dev/staging/prod. Use reversible migrations, canary/blue-green only where architecture justifies, rollback and post-deploy verification. Deployment to production or public store requires explicit authorization. Store release evidence and rollback steps.
