# Performance and accessibility

Establish field and lab baselines before optimizing. Measure Core Web Vitals (LCP, INP, CLS), key task timings, extension overhead, API p50/p95/p99, scan latency, cache hit ratio and failure rate. Set budgets per route/device/network and monitor regressions in CI. Target WCAG 2.2 AA; test keyboard, focus order, contrast, zoom/reflow, reduced motion, screen readers and touch targets. Cover narrow 320px widths through ultrawide layouts and high-DPI devices. Optimize images/fonts, code splitting, hydration, rendering, requests, database plans and caching. Never trade away security/privacy for speed.
