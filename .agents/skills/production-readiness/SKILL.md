# Production readiness

Verify functional scope, security controls, privacy disclosures, licenses, threat model, test evidence, performance, accessibility, browser/store policy, observability, incident response, backups, restore, rollback, cost model, support, billing, legal review and customer communications. Produce a go/no-go report with unresolved risks and named approvals. No production readiness claim without evidence.
