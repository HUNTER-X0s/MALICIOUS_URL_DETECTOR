# Documentation keeper

After each meaningful task, update status, milestone, next actions, backlog, decisions, research index and evidence links. Preserve generated implementation specifications, agent task prompts, architecture diagrams, code review and test reports. Keep a canonical index and remove contradictions by recording a dated decision, not silently rewriting history. Identify stale docs and broken links. Never store secrets or personal data in documentation.
