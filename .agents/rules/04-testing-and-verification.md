# Testing and independent verification

- Never claim checks passed unless run and evidence saved.
- Maintain unit, component, integration, contract, API, E2E, regression, smoke, browser/extension, accessibility, visual, performance, load/stress/soak, fuzz, adversarial, privacy, security and resilience coverage as appropriate.
- Use deterministic synthetic fixtures and isolated environments.
- Security-critical features require independent review and negative tests. Fixes need regression coverage.
