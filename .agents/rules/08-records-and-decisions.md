# Records and decisions

- Persist plans, generated prompts, specs, research, ADRs, test output, security reports, screenshots and release evidence.
- Update status/next actions at every milestone. Use stable IDs, dates, versions and links.
- Never fabricate tests, citations, approvals or deployment status.
