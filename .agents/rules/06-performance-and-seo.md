# Performance and discoverability

- Define and measure performance budgets. Track Core Web Vitals, API p50/p95/p99, scan latency and extension overhead.
- Optimize rendering, bundles, queries, caching and graceful degradation.
- SEO applies to public crawlable website pages; browsers are not separate search engines. Extension discovery is through compliant store listings.
- Never expose scan results or submitted URLs to indexing by default. Never keyword-stuff or promise rankings.
