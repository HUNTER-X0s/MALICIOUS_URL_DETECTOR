# UI/UX, trust and accessibility

- UX is a high-priority workstream; research before selecting visual direction.
- Build original cohesive design system; do not copy Google/Meta or combine every trend.
- Show evidence, confidence/uncertainty, freshness, limitations and safe next actions. Unknown is not safe.
- Test tiny/mobile, tablet, laptop, desktop, large and ultrawide. Test extension popup separately.
- Target WCAG 2.2 AA; manually verify keyboard, focus, contrast, zoom/reflow, screen reader and reduced motion.
- Avoid fake metrics/reviews/trust badges, fear patterns and needless animation.
