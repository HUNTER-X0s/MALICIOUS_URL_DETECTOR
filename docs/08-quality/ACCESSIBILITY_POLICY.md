# Accessibility policy

Target WCAG 2.2 AA for web and extension experiences. Validate semantic structure, accessible names, keyboard-only operation, visible focus, focus order, contrast, reflow, text resizing, target size, error identification, labels/instructions, reduced motion, screen reader behavior, announcements of asynchronous scan results and no color-only verdict encoding. Automated tools are screening, not conformance proof. Perform manual tests with representative assistive technologies and users where feasible.
