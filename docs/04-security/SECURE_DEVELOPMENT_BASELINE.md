# Secure development baseline

Use OWASP ASVS 5.0 as an application verification catalogue, OWASP Top 10:2025 for awareness, NIST SSDF SP 800-218 for secure development practices and CISA Secure by Design as additional guidance. Select applicable controls, record tailoring and verify actual implementation. These references are not a certification claim.

Baseline engineering controls: secure defaults; least privilege; server-side authorization; explicit input/output schemas; parameterized queries; output encoding; safe errors; CSRF protections where applicable; secure cookies; rate limits; resource budgets; dependency and secrets management; encryption in transit/at rest; key rotation; audit logging without secrets; backup restore tests; build provenance; security response and disclosure process.
