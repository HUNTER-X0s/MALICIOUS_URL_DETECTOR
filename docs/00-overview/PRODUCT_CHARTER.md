# URLSentinel Product Charter

## Mission
Help people and organizations make better-informed decisions about potentially malicious URLs through fast, privacy-conscious, evidence-backed analysis and layered protection.

## Product surfaces
1. Public website and URL analysis experience.
2. Browser extension (Chromium first; Edge and Firefox compatibility evaluated separately).
3. Detection API and SDK for developers.
4. Threat-intelligence ingestion and management.
5. Isolated deep-analysis/scanning environment, only after its security boundary is independently proven.
6. Business/enterprise console, tenancy, audit and policy capabilities when validated by customer need.
7. Analyst/community workflows where abuse, privacy, moderation and provenance controls are designed.

## Target groups
Consumers, students/families, professionals, SMBs, security teams, developers, researchers and regulated organizations. Validate distinct needs; do not pretend one interface fits all.

## Product principles
Security first; evidence over reassurance; privacy by default; fast and accessible; explainable outcomes; graceful abstention; minimal permissions; measurable reliability; no dark patterns; commercial/legal integrity.

## Product promise boundary
URLSentinel provides a risk assessment based on available evidence at a point in time. It does not guarantee a URL is safe, detect every malicious link, or replace endpoint/email/network security. `UNKNOWN` is an acceptable and important outcome.

## Success measures
Measure detection quality on representative, licensed, time-aware test sets; false-positive burden; false-negative review; time-to-verdict; service availability; extension overhead; user comprehension/trust; accessibility; privacy incidents; and customer value. Define targets only after baseline and operational capability are known.
