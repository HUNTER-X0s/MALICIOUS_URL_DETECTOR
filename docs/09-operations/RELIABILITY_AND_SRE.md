# Reliability and SRE baseline

Define service ownership, SLIs/SLOs, error budgets, capacity, dependency mapping, alert thresholds, paging/support capability and cost budgets before promising availability. Instrument request/scan queue latency, verdict completion, source freshness, scanner utilization, API errors, queue delay, extension/backend failures and provider availability.

Plan graceful degradation, circuit breakers, queue backpressure, idempotency, rate limits, retry budgets and regional dependencies. Maintain runbooks, on-call coverage or clearly stated support hours, incident communication, vulnerability disclosure, backup restore tests, disaster recovery objectives and recovery exercises. Never claim 24/7 operations without staffing and exercises.
