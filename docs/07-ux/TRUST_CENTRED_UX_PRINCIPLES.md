# Trust-centred UX principles

Trust is earned through truth, not visual symbolism. A visually polished interface cannot make an uncertain assessment certain.

- Show exact verdict language, what was checked, what was not checked, evidence freshness and limitations.
- Separate verdict, confidence, risk score and recommended action.
- Explain why a URL is suspicious in plain language without publishing a full attacker playbook.
- Present unknown, inconclusive, unavailable, stale, suspicious and malicious as distinct states.
- Avoid fake trust badges, fabricated scan counts, fabricated testimonials, unsupported certifications, fear-based copy and manipulative countdowns.
- Make user actions reversible and explain consequences.
- Never use green/check icons to represent “guaranteed safe”.
- Respect privacy: don't expose full scanned URLs in page titles, analytics, logs or public share URLs.
- Design for people with low security knowledge and assistive technology.
- Conduct usability studies that test comprehension, not only visual preference.
