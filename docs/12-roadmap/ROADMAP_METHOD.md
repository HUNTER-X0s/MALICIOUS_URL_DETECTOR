# Roadmap method and suggested milestones

Antigravity must independently research, estimate and generate a detailed roadmap before implementation. Suggested milestones (not a rigid phase-by-phase prompt sequence):
- M0: repo/workspace inspection, goals, constraints, research plan, open questions and permission audit.
- M1: requirements, personas, threat model, UX research, compliance/provider research and measurable NFRs.
- M2: architecture, data contracts, ADRs, test strategy, design system prototypes and deployment design.
- M3: secure project foundation, CI, observability, schema, API skeleton and design system.
- M4: non-network URL parsing and baseline detection with synthetic/adjudicated fixtures.
- M5: provider ingestion and controlled reputation lookup with licenses/quotas.
- M6: domain/DNS/TLS/redirect services in controlled boundary.
- M7: public website MVP and browser extension MVP.
- M8: advanced detection and ML experiments with rigorous evaluation.
- M9: isolated deep scanner only after boundary validation and independent security sign-off.
- M10: auth, history, API productization, feedback, admin workflows.
- M11: enterprise capabilities only after customer validation.
- M12: production hardening, external assessment, operational readiness and controlled launch.

Milestones can be reordered/combined based on dependencies and evidence. No phase is complete by narrative alone; it needs acceptance tests, reports and decision records.
